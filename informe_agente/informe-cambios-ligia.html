4. Al loguearse → el Navbar muestra su email + botón "Salir"

🌤️2. Integración API Open-Meteo (Clima)

Open-Meteo es una API gratuita y sin API key que proporciona datos climáticos en tiempo real. Se usa para obtener condiciones meteorológicas de Puente Alto y cruzarlas con el catálogo de cultivos.

ArchivoQué hace
src/lib/crop-matching.ts Lógica central de matching. Evalúa cada cultivo con un puntaje de 0 a 100 basado en 5 factores climáticos.
src/app/api/cultivos/route.ts Endpoint /api/cultivos. Consulta el clima y retorna los cultivos rankeados por aptitud.

Sistema de Puntuación (Score 0-100)

FactorPesoDato de Open-Meteo usado
Temperatura ambiente35 ptstemperature_2m_min, temperature_2m_max
Temperatura del suelo20 ptssoil_temperature_6cm
Época de siembra25 ptsMes actual vs. meses recomendados
Necesidad de riego10 ptset0_fao_evapotranspiration + precipitation_sum
Radiación UV10 ptsuv_index_max

Un cultivo se considera APTO si su score es ≥ 50 y la temperatura mínima prevista no mata la planta.

Endpoints Disponibles

/api/cultivos → Todos los cultivos con su score
/api/cultivos?aptos=true → Solo los aptos para sembrar ahora
/api/cultivos?categoria=hortaliza → Filtrar por categoría
/api/cultivos?dificultad=facil → Filtrar por dificultad
/api/cultivos?espacio=maceta → Filtrar por espacio mínimo
/api/cultivos?busqueda=tomate → Buscar por nombre

CategoríaCantidadEjemplos
Hortalizas17Tomate, lechuga, zanahoria, espinaca, papa, cebolla, ajo, pepino, zapallo, brócoli
Legumbres6Poroto verde, poroto granado, arveja, haba, lenteja, garbanzo

Datos incluidos por cada cultivo

  • Temperatura mínima tolerada, óptima (min y max), y del suelo para germinar
  • Necesidad hídrica (baja/media/alta) y tolerancia UV
  • Meses de siembra recomendados para zona central
  • Días hasta cosecha, profundidad de siembra, distancia entre plantas
  • Dificultad (fácil/media/difícil) y espacio mínimo (maceta/jardinera/suelo)
  • Tips de cultivo, plantas compañeras e incompatibles
